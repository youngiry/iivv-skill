# iivv 接入指南

文档核对日期：2026-10-23。以完整 Skill 文件夹或 ZIP 为优先选择；纯提示词版提供相同中文接梗规则及固定版本图片地址。

## DeepSeek Harness（DSH）

兼容性核对：2026-11-04 对照最新发布的 [dsh-v0.2.2-alpha.3](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.2-alpha.3)（预发布版，2026-11-03 发布）及主分支提交 [8bd0733](https://github.com/deepseek-ai/deepseek-harness/commit/8bd073392eef6f54e921a093b95076248eb08cbb)，检查文件系统 provider 的目录发现、SKILL.md 元数据解析、默认调用权限，以及 tool-skill 的 `/iivv` 调用入口。安装路径、完整资源布局和当前元数据符合该版实现；5 组本地安装测试通过。此核对属于源码兼容性与安装测试，尚未在真实 Harness 模型会话中完成文字回复和图片展示的端到端测试。

本节核对日期：2026-11-04。使用 Harness 的文件系统 Skill 机制，正式调用名为 `iivv`。安装前需有 Git、Node.js 18+ 和可用的 Harness 环境；Harness 自身的 Node.js 要求以其官方说明为准。

### 安装与调用

```sh
git clone https://github.com/youngiry/iivv-skill.git
node iivv-skill/scripts/install-deepseek.mjs
node iivv-skill/scripts/install-deepseek.mjs --check
```

安装目录默认是 `~/.dsh/skills/iivv/`，环境变量 `DSH_HOME` 可改变配置根目录。安装器复制整个 `skills/iivv/`，校验所有文件字节与图片清单中的 SHA-256，并打印实际位置。无需 API Key 即可执行安装；对话使用 Harness 已有的模型配置。

在 Harness 聊天框输入：

```text
/iivv 开启咒回模式，标准发癫，表情包自动。
```

再试“失礼了，我们可是纯爱啊”。需要恢复普通回答时发“正常说话”。别名用于搜索和自然语言请求；斜杠调用使用 `/iivv`。

### 目录选择与更新

项目级安装（将引号内路径替换为实际项目目录）：

```sh
node iivv-skill/scripts/install-deepseek.mjs --project "/path/to/project"
```

安装器寻找该目录最近的 `.git` 上级，写入其 `.dsh/skills/iivv/`；没有 `.git` 时使用指定目录。启动 Harness 会话时使用对应项目。路径含空格时保留引号。

若 Harness 显式配置了自定义 `dshHome`，指定相同目录：

```sh
node iivv-skill/scripts/install-deepseek.mjs --dsh-home "/path/to/dsh-home"
```

更新已安装版本：

```sh
git -C iivv-skill pull --ff-only
node iivv-skill/scripts/install-deepseek.mjs --update
node iivv-skill/scripts/install-deepseek.mjs --check
```

使用项目或自定义目录时，更新与检查也需带相同目录参数。已有安装默认不会覆盖；`--update` 先把旧目录移入相应 DSH 配置目录的 `skill-backups/`，再安装新版，并打印备份位置。卸载时删除实际安装位置的 `iivv/` 文件夹即可。

### 手动安装与加载排查

也可从标准 ZIP 解压出完整 `iivv/` 文件夹，直接放进 Harness 的 `skills/` 根目录。正确结构为 `~/.dsh/skills/iivv/SKILL.md`，同级保留 `references/`、`assets/` 和许可证。不要把整个仓库放进扫描目录：Harness 不递归寻找多层嵌套的 `SKILL.md`。

自定义 Harness 组合需启用以下三个官方组件（在现有插件配置中确认；不覆盖整个配置）：

```yaml
- name: '@deepseek-ai/dsh-skill'
- name: '@deepseek-ai/dsh-skill-filesystem'
- name: '@deepseek-ai/dsh-tool-skill'
```

默认文件系统 provider 会监视目录变化，在后续模型步骤更新技能目录。若 `/iivv` 未加载，检查这三个组件、`includeDefaultRoots` 是否启用，以及安装位置是否与运行 Harness 的机器、账户和 `dshHome` 一致。远程/容器运行的 Harness 应在它可访问的文件系统中安装。项目 `.dsh/skills` 和 `.agents/skills` 中的同名技能优先于用户级安装，排查时也应检查这些位置。

图片显示取决于 Harness 前端提供的图片/附件能力；纯文字终端可使用文字接梗和图片链接。`--check` 验证安装文件，文字回复及图片实际展示需在自己的 Harness 会话中验收。

本仓库测试：`node --test scripts/test-install-deepseek.mjs`，涵盖完整安装、字节检查、损坏检测、拒绝覆盖、备份更新、`DSH_HOME`、项目根识别和错误参数。测试不调用模型 API。

官方依据：[文件系统 Skill provider](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/skill/skill-filesystem/README.md)、[Skill 工具与斜杠调用](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/skill/tool-skill/README.md)。

## Grok Bot

Grok Bot 官方支持把书面流程保存成私有 Skill，并通过 `/` 菜单调用。管理入口为“连接应用 → 你的插件 → 管理插件和技能 → 私有技能”（界面可能显示对应英文名称）。

把仓库链接和标准 ZIP 交给 Bot，附上：

```text
请读取 https://github.com/youngiry/iivv-skill 的 skills/iivv/，
包括 SKILL.md、references/、assets/ 和素材说明。
将完整内容保存为名为 iivv 的私有技能，并按实际保存结果告诉我调用入口。
启用后用中文咒术回战梗接话，标准浓度，图片自动；实际任务照常完成。
```

图片可用共享工作区文件或固定版本远程地址；附件方式以当前 Bot 提供的工具为准。

官方依据：[技能、流程与自动化](https://docs.x.ai/grok-bot/skills-routines-and-automations)、[文件与结果](https://docs.x.ai/grok-bot/files-and-results)。

## 腾讯 WorkBuddy

下载 `iivv-workbuddy-v1.0.0.zip`。在左侧“专家·技能·连接器 → 技能 → 添加技能 → 上传技能”导入，随后在聊天中调用 iivv。界面版本如提供的是“创建技能”，可将 ZIP 与下方说明交给创建流程。

```text
请将附件保存为 iivv 技能，完整保留参考资料和图片。
采用中文回复，优先接住用户抛出的咒回梗，再完成实际任务。
```

适配包补齐 `description_zh`、`description_en`、`version`、`author` 等平台字段，正文与说明为中文。`description_en` 是平台必填的机器元数据；仅此字段提供简短英文简介。图片放在 `references/images/`，索引及清单同步换路径，并保留远程备用地址。

官方依据：[技能市场](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)、[开放平台技能结构](https://open.workbuddy.cn/docs/skill)。
